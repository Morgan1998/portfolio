## Why Vanilla Javascript?

I wanted to create a meaningful project that provides me with a playground to keep practicing vanilla javascript. I don't want to
get too lost in the abstraction of React! Within this project I can:

- Practice typescript without a framework
- Practice writing factory functions (or classes if I want to get funky with it)
- Practice using DOM API methods like `document.createElement()`, `element.append()`, `document.querySelector()`, among others.
- Practice using Tailwind with vanilla javascript
- Be reminded of how routers work under the hood

... and most importantly, just being reminded of how lovely libraries/frameworks, like React, really are. Declarative coding is so much better.
